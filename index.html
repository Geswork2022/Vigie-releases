Installation macOS

  1. Décompressez l'archive téléchargée (double-clic).
  2. Double-cliquez Installer VIGIE.command.
  3. L'application n'étant pas notarisée par Apple, macOS peut la bloquer au 1er lancement. Ouvrez alors → Réglages Système → Confidentialité et sécurité, puis, en bas, cliquez sur « Ouvrir quand même » (une seule fois).

Pour une Micrologic X en USB direct sur Mac, installez d'abord libusb : brew install libusb (inutile avec la valise Service Interface LV485500).
